# Workspace resources

Resources are primarily **images** (and optional PDFs) intended for **branding** — workspace logos and [project](/manage/project/) themes (backgrounds / wallpapers). Upload them once, then select them when configuring branding in workspace settings or a project theme.

They can also be used as default email attachments for invite / joined messages.

**Prerequisites**

- Signed in as an administrator or employee at <https://accsyn.io/admin/resources>.

## What you can upload

Allowed file types:

- **JPEG / JPG / PNG** — logos and theme backgrounds
- **PDF** — typically for email attachments

### Recommendations

- **Logotypes** — Scaled down to fit within **40px** height and **140px** width. Ideal aspect ratio is **7:2**.
- **Project theme backgrounds** — Aspect ratio **16:9**, at least **1000px** wide.

## Resource list

Open **Workspace → Administrate → Resources** (or go to <https://accsyn.io/admin/resources>).

The list shows:

- **Preview** — Thumbnail for images; PDF icon for PDFs
- **Filename**
- **Dimensions** — Width × height when available (images)
- **Creator**
- **Created**
- **Actions** — Rename or delete

Sort by filename or created date by clicking the column headers.

## Upload a resource

1. Click **Upload resource**.
2. Choose a JPEG, JPG, PNG, or PDF file.
3. The file is stored for the workspace and appears in the list.

Use the uploaded file as:

- Workspace **logo** (light / dark) in [Workspace settings](/admin/settings/)
- Project **theme background** (and related branding) in [Projects](/manage/project/)

## Rename a resource

Click the pencil icon on a row, edit the filename (keep a valid extension: `.jpeg`, `.jpg`, `.png`, or `.pdf`), then **Save**.

## Delete a resource

Click the trash icon and confirm. Deletion removes the file and **unlinks** it from places it was used (for example the workspace logo).

*Note: This cannot be undone. Prefer renaming or replacing branding references before deleting an asset still in use.*

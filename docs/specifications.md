# Specifications

## Technical specifications

Rev 1.004, 08.10.26

### General

| Item | Specification |
|---|---|
| Type | Managed File Transfer (MFT) Software as a Service (SaaS) — a cloud-hosted private instance that orchestrates accelerated peer-to-peer file transfers with cloud-hosted or on-premises (BYOS) server storage, providing file deliveries, compute (render farm), and media management capabilities. |
| User interface(s) | Desktop application (Windows, macOS & Linux), web application (mobile-friendly), CLI (command-line interface), and Python/JavaScript APIs. |
| Platforms | Windows™, Unix/Linux™, and macOS™. Modern evergreen browsers (Chrome, Firefox, Edge, Opera, Safari). |

### Security

| Item | Specification |
|---|---|
| Hosting | VPC (isolated virtual private cloud instance), ISO 9001/14001/27001 certified hosting. |
| Internal communication | TLS/SSL REST & GraphQL (HTTPS on port 443). |
| File transfer | Software-firewalled server endpoint, 256-bit PSK authorisation, encrypted using 128-bit Advanced Encryption Standard (AES-128, default) or AES-256 (configurable). More information in the [Whitepaper](/whitepaper/). |
| Authentication provider | Identity delegated to a configured identity service (accsyn accounts and supported external providers such as Google and Microsoft). No user passwords are stored with or distributed by accsyn to transfer peers. |
| Certification(s) | HBO® (Home Box Office), for use in sensitive film production. |
| Signup and authorisation | Self signup and workspace creation, with email verification. Login to accsyn is mandatory for all users before they can access any data. |
| Proxy | SOCKS (v4 & v5) support. |

### File transfer

| Item | Specification |
|---|---|
| Protocol | Proprietary accelerated file transfer protocol over TCP (default port range: 45190–45209) and HTTPS web deliveries. |
| Synchronisation algorithm | Compatible with UNIX rsync semantics; resumes where it left off by comparing and storing file size and modification dates. Additional one-way sync mode deletes files that do not exist on the source. |
| Speed | On average 2–5× faster than FTP and HTTP downloads, depending on network conditions. |
| Office-to-office | Supports site servers for push and pull between main headquarters and satellite offices, or employees working from home. |
| Web deliveries | Deliver files securely in the browser, with ZIP compression of folders and multiple files. Upload requests feature an accelerated browser uploader supporting multiple files. |

### Collaboration/File sharing

| Item | Specification |
|---|---|
| Admin/employee disk/storage access | Confined access to one or more volumes — directories on local or cloud storage. |
| User access | Through shared folders acting as collaborative work areas, or file collections. Both shares and users can be bound to a queue. |
| Permissions | Role-based access control (RBAC); file access defined by ACLs (Access Control Lists). |
| User mapped shares | Option for users to map a share locally so elevated operators can pull (upload from the client) and push (download to the client) while the remote client is online. Option to install accsyn as a User server (daemon/service) for 24/7 local sharing without the Desktop App running or a user logged in. |

### Transfer management

| Item | Specification |
|---|---|
| Jobs | Hierarchical job structure with sub-tasks, each task being a file or folder on a share (server) or local disk (clients). |
| Queues | Queue system with individual settings such as priority, bandwidth, and hooks. |
| Prioritising | Transfer jobs can be re-ordered, re-queued, paused, resumed, and aborted through the user interfaces. |

### Render & transcode farm

| Item | Specification |
|---|---|
| Farm | Install accsyn as a render server, enabling execution of custom Python render app wrapper scripts. |
| Supported renderers | ffmpeg, Maya, Nuke, Unreal Pixel Streaming, Houdini, and more. |
| Wrapper render scripts | Highly configurable render scripts, available as open source. |


### Media Vault

| Item | Specification |
|---|---|
| Structure | Main title folders linked to IMDb movie titles, available on accsyn Cloud Hosted Storage. |
| Media logging | Categorising and tagging of media — images and movies beneath main title folders, with metadata. |
| Proxies | Thumbnails and low-resolution image and video proxies generated by default within the platform. |
| Transcoding | ffmpeg cluster featuring low-resolution and VOD deliverable transcodes supporting most common formats. |
| Streaming | Supports web HLS streaming of video files, driven by the accsyn Delivery subsystem. |
